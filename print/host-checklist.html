Host checklist — one strange evening

Print at 100%. For 4–12 adults. Paper, pens, a timer. No app.

  • Count chairs around one table. Two teams if 4–8 guests; three if 9–12.
  • Print the game kit on card stock. Keep the host answer page in a separate folder.
  • Put a kitchen timer in the middle. Phones stay in a bowl by the door if people agree.
  • Water + one snack bowl before drinks. Spills kill cards.
  • Explain passing in the first 30 seconds. Nobody has to perform.
  • 0–5 min: team names. 5–15: riddles. 15–25: forbidden words. 25–40: alibis. 40–55: choices. 55–70: last line.
  • Skip a round rather than run long. End on a vote, not a lecture.
  • Have a 10-minute physical card game in a drawer if the writing round dies.
  • Lights: overhead off, one warm string on. Guests need to read paper.
  • After: recycle the cut cards or clip them for next year. Do not post guests’ written stories without asking.
